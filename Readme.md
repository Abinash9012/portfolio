# Abinash Sarangi — The Series

A cinematic, responsive personal portfolio built with React, TypeScript, Vite, Tailwind CSS and Framer Motion. The content focuses on networking, CCNA training, systems administration and cybersecurity.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```
